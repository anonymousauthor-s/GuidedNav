1"""vln_sampling.py — the SINGLE source of truth for VLN history-frame sampling.23``history_indices`` defines which past frames become the ``<memory>`` block of a4VLN prompt. It is imported by, and must stay identical across:56  * ``data_process/build_vln_samples.py``  — bakes the indices into each offline7    per-step record (training).8  * ``qwenvl/eval/eval_discrete_action.py``   — rebuilds them during rollout.9  * ``qwenvl/eval/eval_continuous_action.py`` — likewise.1011This module exists because those three drifted apart once already and it cost a12full eval cycle: the continuous evaluator sampled the last N *consecutive*13frames (~1.75 m of trajectory) while training sampled uniformly over the whole14trajectory. The mismatch erased global instruction progress from the memory15block and made the stop head look untrained — the same checkpoint went from16SR 0 to SR 0.35 once the rollout fed the training distribution, with no17retraining. Any change here must be made ONCE, here, and re-run through18``build_vln_samples.py`` (the offline records cache the indices).1920Deliberately numpy-only: ``build_vln_samples.py`` runs 48-way sharded with no21torch/transformers in the process, so this must not pull in the heavy stack.22"""2324from typing import List2526import numpy as np272829def history_indices(c: int, memory_size: int) -> List[int]:30    """History frame indices for a decision at frame ``c``: uniform over the31    whole traversed trajectory, current frame excluded.3233    ``linspace(0, c, memory_size)``, rounded to ints and de-duplicated, keeping34    only ``j < c``. Consequences worth knowing, since prompts are variable-length35    and every consumer must reproduce the same ramp:3637    * ``c == 0`` -> ``[]``. The caller must then omit the whole "These are your38      historical observations: <memory>." clause, not emit an empty one.39    * ``1 <= c <= memory_size - 1`` -> ``[0, 1, ..., c-1]``: EVERY traversed40      frame, no subsampling. Early-episode history is lossless.41    * ``c >= memory_size`` -> saturates at ``memory_size - 1`` frames (7 for the42      default ``memory_size=8``), because the ``linspace`` endpoint ``c`` is the43      current frame and gets filtered out. The name says 8, the block holds 7 —44      intentional, and identical on both sides.4546    Note the span keeps growing with ``c`` while the count stays fixed, so late47    in a long rollout consecutive memory frames are tens of steps apart. Training48    only ever sees ``c`` up to the GT trajectory length, so a rollout that wanders49    far past it drifts out of distribution here — a known limitation, not a bug.50    """51    if c <= 0:52        return []53    raw = np.linspace(0, c, memory_size)54    idxs = sorted({int(round(x)) for x in raw})55    return [j for j in idxs if j < c]
