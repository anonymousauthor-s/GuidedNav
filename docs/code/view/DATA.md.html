Render the released training poses3233The frozen final-stage package preserves the original per-video trajectory NPZ files. They store world-space **agent** positions and rotations in **w,x,y,z** order, with one pose per observation. Their filenames match the video basename in each annotated row. `tools/render_training_rgb.py` converts to Habitat's x,y,z,w coefficients and reapplies the camera offset once. It does not rerun a shortest-path follower or sample a different trajectory.3435In the simulator environment, from `code/`:3637```bash38python tools/render_training_rgb.py \39  --trajectories ../data/r2r/traj \40  --scenes-root ../data/scene_datasets \41  --output ../data/r2r/rgb42python tools/render_training_rgb.py \43  --trajectories ../data/rxr/traj \44  --scenes-root ../data/scene_datasets \45  --output ../data/rxr/rgb46```4748Use `--rank i --world-size N --gpu j` to shard videos across rendering workers, and `--limit 1` to inspect one trajectory first. The renderer writes `images/<video>/rgb/001.jpg`, matching recorded relative image paths. It renders every pose of each selected trajectory, covering uniform-history images and the three local predecessor frames required for temporal fusion. Existing frames are retained. Use a fresh output directory when changing simulator/sensor settings.4950The source collection code wrote RGB JPEGs using Pillow's default JPEG settings. The renderer uses the same save operation, but byte-for-byte RGB reproduction has not been verified during packaging; renderer, driver and JPEG library differences can change pixels. Use original RGB assets and their integrity records when available. Before training, inspect a rendered frame and its released object mask at the same frame index. This is especially important because the masks supervise spatial attention on the rendered current observation.5152## 3. Verify and relocate frozen training data5354The final stage selects 157,465 of 629,862 R2R source rows and 472,323 of 1,889,294 RxR source rows: 629,788 total. Sampling is row based, seed 42, without replacement, using annotation-complete candidates. It is not a random 25% of trajectories. The candidate snapshot is fixed; later completed exports must not alter the selection.5556Each source has JSONL records and seven `.npy` arrays: `offsets` (byte offsets), `source_indices` (original row identities), `spans` (subtask character bounds), `phases`, `groups`, `weights` and `o_eligible`. S weights are balanced across selected trajectory phases and normalized within each source. R2R and RxR both use their released object masks. No visible-object mask means missing supervision, not a negative object target.5758Use the anonymous data package's manifest, not a newly sampled dataset. After extraction, relocate and verify it:5960```bash61python tools/prepare_data_manifest.py \62  --manifest ../data/manifest.json --array-root ../data \63  --r2r-jsonl ../data/r2r/samples_perstep.jsonl \64  --rxr-jsonl ../data/rxr/samples_perstep.jsonl \65  --r2r-rgb ../data/r2r/rgb --rxr-rgb ../data/rxr/rgb \66  --r2r-masks ../data/r2r/masks --rxr-masks ../data/rxr/masks \67  --output ../data/manifest.local.json68```6970If the data package uses different JSONL or mask subdirectory names, pass those actual locations. Mask roots must be the directories against which the row's relative `object_supervision.active_masks[].mask` paths resolve. The anonymous export preserves original selected-row identities and targets while replacing private paths and, when compacting the JSONL, recalculating byte offsets. Its manifest records the original full-manifest SHA256 `cf78986d6a58f22be9bacc707e4b3d7f630d60940e2a7acc50e7d7cfddceb33f` in export provenance. Its new manifest/JSONL/offset-array byte hashes therefore differ from the private source; that is not a different row selection. The relocation tool verifies the anonymous export's immutable JSONL and array hashes, updates filesystem modification times, and writes a new manifest without modifying the frozen reference. Run the two-update gradient smoke in README.md before a formal distributed run.8182## Annotation schema and provenance8384Rows contain `instruction`, chronological relative `images` (history followed by one current frame), `n_memory`, `conversations`, `action_text`, current step `c`, `subtask`, `subtask_phase_index`, and `object_supervision`. The latter records `mask_loss_eligible` and `active_masks`, whose entries retain mask filenames, hashes, frame/phase identities and pipeline metadata. RxR rows additionally retain their original instruction identity. Exact character spans and group weights come from the sidecars; do not approximate them by a different tokenizer search.8586The data loader sanitizes legacy subtask-answer text into an action-only policy target. Ground-truth subtasks, character spans and object masks supply training losses only. They are not included in the inference prompt. The current-frame spatial-forcing weight is 0.5, temporal-difference weight 0.1, native subtask/object weights 0.01 each, with a 0.03 auxiliary warmup ratio.8788`tools/regenerate_expert25.py` preserves the selected run's sampling/export logic with explicit path arguments. It can regenerate the selection **if** the original full-source indexed R2R manifest/arrays, frozen RxR completed-case snapshot and schema-v2 completed exports are available:8990```bash91python tools/regenerate_expert25.py \92  --prior-full-data /path/to/full-indexed-data \93  --rxr-completed-exports /path/to/completed-schema-v2-exports \94  --completed-snapshot /path/to/frozen/rxr_completed_snapshot.json \95  --output /path/to/new-selection96```9798Those upstream annotation-production inputs are not required to train from the already frozen released data package. This script does not regenerate subtask/object labels by invoking a different VLM or segmenter, which could produce different labels. The released labels and masks define the reproducible final-stage targets.99100For collecting **new** expert datasets, `src/data_process/gt_following_rollout.py` and `build_vln_samples.py` expose `--help`; the latter uses memory size 8, four future actions and seed 42.
